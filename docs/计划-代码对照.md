### 6.1 关于踏云闪「需已起跳」

代码里 `EntityForm` 的冲刺条件带 `jumpCount >= 1`，来自 GDD 早期设定「二段跳的第二跳即踏云闪」。
规划 v2.0 把踏云闪改成了**独立闪避键（K，无需起跳）**，两边不一致。

**当前保留「需已起跳」**，因为改成地面也能冲会直接影响手感与关卡节奏，属于设计决策，**待团队确认后再动**。
若要改，只需去掉 `EntityForm` 里的 `this.jumpCount >= 1` 条件（一行）。

输入事件名（临时）：`[Combat][diag]` 之外，攻击相关日志前缀统一为 `[Combat]`。

## 8. 已知的坑（改代码前先读）

| 坑 | 说明 |
|---|---|
| **判定盒碰撞体 offset 必须为 0** | `CombatController` 只翻转**节点位置**做左右镜像，`BoxCollider2D.offset` 不跟着翻。`onLoad` 会把 offset 折进节点位置并归零做兜底，但别在 Inspector 里设 offset |
| **命中盒刚体类型必须是 `Animated`** | `Static` 的 fixture 不跟随节点移动；`Dynamic` 会休眠（休眠后接触事件不触发）。两者都会导致"攻击时灵时不灵" |
| **连击窗口从收招计时** | 若改回从起手计时，窗口(0.3s) < 攻击时长(0.4s)，连段永远不会接上 |
| **换美术素材要改「天然朝向」常量** | `QingheController.ART_NATURAL_FACING`（当前 `1`＝朝右）、`CombatController.SLASH_NATURAL_FACING`（当前 `1`）。判错会导致"攻击打到背后" |
| **预览运行时无法保存场景** | 必须先停止预览再 `Ctrl+S`，否则 `save` 会"看起来成功"但文件不写 |
